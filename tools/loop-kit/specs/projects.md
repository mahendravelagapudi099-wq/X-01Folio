# Projects spec
- Audit every card, repo link, demo link, image, modal.
- Remove placeholder URLs. Never label a GitHub repo "Live Demo". Show GitHub
  when a valid repo exists; "Source Code" when no demo.
- Fix SentimentScopex image path (case sensitivity matters on Linux hosts).
- Consistent image ratio, badges, keyboard and touch friendly, strongest first.
- Case study sections (omit any with no real info): Problem, Motivation, My
  contribution, Architecture, Key decisions, Challenges and solutions, Verified
  results, Repo/Demo. Never invent results.
- Filtering only if there are enough projects to justify it.
