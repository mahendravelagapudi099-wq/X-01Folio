# Design spec
- Hero: name and role clear at once; headline on Computer Science, Data
  Science, AI/ML, software development (accurate claims only); short support
  text; actions View Projects, Contact Me, Resume; GitHub/LinkedIn when set.
- No overflow or overlap at 320/375/768/1024/1440. Keep profile image,
  code-themed visuals, and animations that add value.
- About: concise, real interests and research direction, no unverified claims.
- Skills grouped: Programming, Web Development, Data Science and ML, Databases,
  Developer Tools. Only skills evidenced in the repo or FACTS.md. No % bars.
- Footer: nav, verified socials, current year, back-to-top. No dead links.
