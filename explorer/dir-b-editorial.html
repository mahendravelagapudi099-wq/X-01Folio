Primary Academic Research

Risk-Based Verification and Evidence-Grounded Self-Correction for AI Data-Analysis Agents

Autonomous coding agents frequently generate syntactically valid pandas and SQL queries that introduce subtle statistical errors—such as distribution shift, bias leakage, or unchecked null imputations. This treatise outlines a two-tier framework: (1) static abstract syntax tree verification to detect high-risk data transformations prior to runtime, and (2) evidence-grounded evaluation oracles requiring intermediate assertion proofs before conclusions are accepted.
